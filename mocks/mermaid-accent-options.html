AZed parity · positional cycle

Color = node DOM order % 8. Zero graph awareness — the zed baseline. Related boxes share nothing.

BGraph-aware · flow depth + edges by source

Color = topological depth from entry nodes; each connector takes its source node's color, so a flow reads as one family. Detect: in-degree-0 sources, BFS layering over L-… ids.

CAuthor intent · subgraph + classDef

Color = the author's grouping: one hue per subgraph (DOM nesting under g.cluster), authored :::class overrides. Needs the diagram to declare context.

DInteractive focus · spot a flow

Base = depth coloring. Hover a node: it + its incident connectors + direct neighbors stay bright, the rest dims. Click pins. Detect neighbors from L-<node>-* / L-*-<node>.

E1b hybrid · subgraph, else positional

Subgraph present → one hue per box (C: all FDE green, all Agent magenta). No subgraph → positional cycle (A). Flat diagrams (decision + loop, viewer flow) match A; the pitch loop matches C.
